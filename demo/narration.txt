Welcome to Intersections Library, a personal book manager built from small Bash programs. The browse view shows an interdisciplinary shelf spanning technology, history, psychology, science fiction, and literature. Every record is stored in a carefully quoted CSV file, while the rest of the application communicates through simple tab-separated streams. Search works across titles, authors, genres, years, reading status, ratings, and links. Metadata comes from a bundled offline catalog, so adding a book never needs an API key or a network connection. For recommendations, three independent agents begin at the same time. One learns from completed and highly rated books. One matches the reader's current interests. The third deliberately explores genres missing from the library. Their results flow through a refinement pipe that removes books already owned, deduplicates candidates, keeps the strongest score, and returns a focused shortlist. The demo uses a temporary database, leaving the real collection untouched. This is Intersections Library: a compact system whose data, workflows, parallel processes, and interface are visible from end to end.
