Welcome to Intersections Library, my offline personal book manager built from small Bash programs. I am running the isolated demo, so it will not change my real library. First, Browse Library displays five books from my interdisciplinary shelf. The table shows each title, author, genre, year, reading status, rating, and link. The data layer reads carefully quoted CSV and sends tab-separated records to this Gum interface. Second, I search for “design.” The search component checks every field and returns only the two matching books. Finally, I request recommendations for technology, history, psychology, and literature. Three independent Bash programs start in parallel. The history agent learns from completed and highly rated books. The interests agent matches my current topics. The discovery agent looks for genres missing from the collection. The workflow prints progress while they run, waits for all three process IDs, and pipes their combined output into the refinement program. Refinement removes books I already own, deduplicates the candidates, ranks them, and presents a five-book shortlist. These three operations show the complete path from terminal input, through workflows and independent components, to clear output.
